# PocketEdge examples

These examples are included in the published package so that Dart and Flutter
developers can copy a complete starting point.

## Basic server

```bash
dart run example/basic_server/main.dart
```

The basic server registers an HTTP route, enables pairing, and starts the local
PocketEdge host.

## Browser client

`web_client/index.html` is a static LAN client demonstrating QR join, pairing,
WebSocket chat, and authenticated file upload.
